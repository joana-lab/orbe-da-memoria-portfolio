# Security & privacy posture

This is a **public case-study repository**. It is curated to contain **no secrets and no
proprietary material**. This document states what is deliberately excluded and how to report a
concern.

## What this repository intentionally excludes

- Production source code and datasets
- Credentials, tokens, API keys, or `.env` content
- Hostnames, server IPs, deployment paths, SSH configuration
- Private or unpublished URLs
- Internal agent instructions / proprietary prompts
- Curated historical dossiers and unpublished research
- Personal contact details (phone, home address, private email)
- Confidential commercial, pricing, or partnership information

## What it deliberately includes

- Product and architecture documentation (sanitised)
- Diagrams of the architecture, AI operating model, and delivery flow
- Fictional / simplified illustrative examples created for this case study

## Handling of the private production repository

The production repository is **private and is the source of truth**. This case study was produced
by **read-only** understanding of that project. Creating this public repository does not modify,
rename, re-permission, or expose the private repository in any way.

## Deployment details

Deployment is described only at the level of *discipline* (controlled deployment with a
served-vs-built verification). Specific hosts, paths, keys, and scripts are intentionally omitted.

## Reporting a concern

If you believe this repository inadvertently contains sensitive information, please open an issue
without restating the sensitive detail, or contact the author via the linked professional
profiles. Reports will be addressed promptly and the content corrected or removed.
