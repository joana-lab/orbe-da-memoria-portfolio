# Screenshots

Captioned screenshots of the **public, live** experience can be placed in this folder and
referenced from the main README.

Guidance for any capture added here:

- Capture only the **public** site — nothing behind a gate, no debug overlays, no dev tooling.
- Verify each image shows **no** unpublished research, private data, personal information,
  internal URLs, credentials, or console/debug output.
- Add a short caption describing the **technical/product capability** the view demonstrates
  (e.g. "contextual Leaflet map activating on a query"), not just what it looks like.
- Prefer stable views over transient states so captions do not drift out of date.
